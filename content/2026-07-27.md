      O Claude Code passou a permitir disparar subagentes que rodam em
      paralelo, cada um com seu próprio contexto. Na prática, você delega
      tarefas independentes — rodar testes, revisar um módulo, pesquisar
      docs — sem poluir a sessão principal.

      Pra quem trabalha sozinho, é como ter estagiários que fazem o trabalho
      de leitura pesada enquanto você foca no código.

      ## Por que importa

      Menos "context rot" na sua sessão longa, e tarefas de investigação
      deixam de travar o fluxo principal. Numa sessão que já dura horas, cada
      arquivo que você manda o agente ler come contexto que faria falta
      depois. O subagente lê, resume e devolve só a conclusão.

    body: |
      A v16 consolidou o App Router como caminho padrão, e a v15 virou LTS de
      manutenção.

      ## O detalhe que pega quem migra

      `params` de rotas dinâmicas agora são assíncronos. Onde antes você lia
      direto, agora precisa de `await`:

      ```js
      export default async function Page({ params }) {
        const { slug } = await params;
      }
      ```

      Sem isso o build não quebra de imediato, mas o valor chega como Promise
      e o erro só aparece em runtime.

<details>
<summary>Gabarito</summary>

1. Cada subagente tem contexto próprio, então tarefas de investigação não
   poluem nem travam a sessão principal.
2. Viraram assíncronos (Promise) — é preciso dar `await params` antes de usar.
